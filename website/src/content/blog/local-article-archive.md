看到值得参考的公众号文章，先明确自己要留下什么：是某个选题的几篇参考，还是某个公众号的一段历史内容。把范围想清楚，比一开始就追求数量更有用。

MPider 是免费开源的 Windows 公众号文章下载工具，支持将正文与图片保存在本机，离线阅读，并同时导出 Markdown 与 HTML。文章版权仍归原作者及权利人所有，只获取和保存你有权处理的内容。

## 保存之前，先确认使用条件

MPider 使用本机已登录的个人微信会话。首次登记公众号、更新会话时，需要你在微信手动打开目标公众号主页；它不会替你点击微信窗口。

当前支持的 Windows 与微信版本、安装要求，均以 [GitHub 正式发行说明](https://github.com/areyoubugcoder/mpider/releases/latest)为准。微信升级后可能需要重新适配，不要把旧版本的验证结果直接套用到新版本。

**所有使用个人微信号的客户端都可能存在封号风险，MPider 也不例外。** 本地运行、开源和低频请求都不能保证账号安全，避免使用承载重要联系人、工作或支付用途的账号。

## 从文章列表到本地正文

1. 在 MPider 的公众号页开启监测，再到微信手动打开目标公众号主页，完成登记。这一步不会自动下载文章。
2. 需要近期内容时，使用“同步最新文章”；需要历史内容时，按追加篇数或截止日期创建历史采集任务。
3. 在文章库选定需要的文章，加入正文下载队列。文章列表与正文下载是两个步骤，看到标题不等于正文已经保存。
4. 正文与图片保存后，可在工作台阅读，或导出到自己指定的文件夹。

如果任务提示需要更新会话，按提示重新打开或刷新该公众号主页。会话更新与任务继续都应以工作台提示为准，不承诺无需人工操作的长期自动采集。

## 用自己的方式整理参考资料

对内容运营来说，可以先按选题建立导出目录，再保留文章标题、来源与原文链接，方便回看和核对。MPider 提供本地留存与导出能力；选题分类、笔记与内容判断仍由你完成。

同一次导出会生成 Markdown 与 HTML。前者适合后续文字整理，后者适合浏览器阅读；具体区别见另一篇[导出格式使用指南](../markdown-and-html-export/)。

## 备份要覆盖完整数据目录

正文、图片、数据库与任务状态不是同一个文件。备份和迁移前，查看“系统设置”显示的数据目录，并按[数据与安装说明](https://github.com/areyoubugcoder/mpider/blob/main/docs/windows-standalone.md)保留完整数据。

不要把数据库、会话文件或未经脱敏的日志发到公开群聊、Issue 或其他网站。本地保存也需要由你妥善管理。
