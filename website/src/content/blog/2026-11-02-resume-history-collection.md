账号是自己的，风险自己承担，导出文章却还要额外付费。这种体验，我不认同。

所以 MPider 选择免费开源，让核心采集逻辑与凭证处理可供核查，把知情权和选择权交还给用户。它能做的事情很直接：公众号监测，以及下载公众号文章的正文和图片，保存到自己的 Windows 电脑，离线阅读，再同时导出 Markdown 和 HTML。

今天说一个实际问题：采集旧文时，临时要关电脑

![任务页可区分首页同步、历史采集和正文下载，便于核对任务状态（演示数据）](../../assets/blog/workbench-tasks.png)

任务页可区分首页同步、历史采集和正文下载，便于核对任务状态。截图为公开版本的演示界面，具体操作以本文注明的版本和最新发行说明为准。

比如，你在整理一个公众号的旧文章，列表采集还没完成，晚上却需要关电脑。第二天再打开，不必先把原任务删掉。MPider 的历史采集会保留检查点；应用重启后，未完成任务保留进度并暂停，由你选择继续。

先分清自己停在哪一步

公众号登记、获取文章列表、下载正文，是不同的步骤。开启「公众号监测」，再在已登录的微信里手动打开目标公众号主页，工具才会登记公众号与会话。监测本身不会自动采集文章，也不是全天自动追踪更新。

登记后，可以点「同步最新文章」获取首页，或者点「采集历史文章」，按追加篇数或截止日期创建历史任务。正文与图片则另行下载。

历史任务暂停后，怎样接着做？

1. 在「任务」中找到原来的历史采集任务，查看状态和进度。只是临时暂停时，保留原任务，按需要继续。
2. 如果提示需要新会话，按说明在微信手动打开或刷新目标公众号主页，等待该公众号的完整新会话登记。
3. 会话更新后，再沿原检查点尝试继续。程序不会替你点击微信窗口；会话更新也不代表所有旧游标都一定可用。
4. 如果更新后仍失败，先停止重复尝试，查看任务提示与日志。不要靠删除任务、手工改游标或只改微信版本号解决问题。

你主动暂停、取消、关闭监测或重启应用后，不要假设原任务仍会自动继续。历史检查点能否续用，以实际任务结果为准，没有统一的有效期保证。

正文下载完，再把文件导出来

文章列表拿到后，在文章库勾选需要的文章下载正文，也可以按需点击公众号行的「下载全部正文」。已有正文会跳过，正文、封面和正文图片保存在本机。

下载完成后再用「阅读 / 导出」，同时得到 Markdown、HTML 和已保存的图片。批量或整号导出前，先完成全部目标正文下载；导出不会自动补采缺失正文。

关闭窗口和退出程序，有什么区别？

关闭主窗口会收起到系统托盘，后台任务仍可能继续。从托盘选择「退出」才结束程序。电脑休眠或关机会中断运行，MPider 不提供自动唤醒；重启后应重新检查任务状态。

下载前先确认环境

当前原生采集面向 Windows 10/11 x64，需要 WebView2，已验证微信 4.1.15.56 x64。微信升级后需要重新适配，macOS、Linux 暂不支持。

所有使用个人微信号的客户端都可能有账号限制或封禁风险，MPider 也不例外。开源、本地运行和低频请求都不是防封保证，请避免使用承载重要联系人、工作或支付用途的账号，只保存自己有权处理的内容。

当前不采集视频、音频、评论、阅读量和互动数据；定时自动增量采集仍是后续计划。
