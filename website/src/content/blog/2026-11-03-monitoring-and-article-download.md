账号是自己的，风险自己承担，导出文章却还要额外付费。这种体验，我不认同。

所以 MPider 选择免费开源，把核心采集逻辑和凭证处理公开出来供大家核查，把知情权和选择权交还给用户。

它的两项核心用途很明确：公众号监测、公众号文章下载。正文和图片保存在自己的 Windows 电脑，可以离线阅读，同时导出 Markdown 和 HTML，不为本工具中的文章导出额外收费。

已发布的 v2.0.0 新增了本地微信推送监测。下面以这个版本为准，讲清楚它与“主页识别”怎么配合使用。

想留住近期文章：用推送监测发现链接

比如，你在电脑上阅读几个行业公众号，想把发现的近期文章归入文章库，之后再挑值得保存的内容下载。

在 Windows 上保持微信登录，打开 MPider 左侧「推送监测」，选择监测范围和扫描频率，再开启监测。可以选择全部公众号，也可以从已登记公众号中选择范围。

工具从本机微信中发现文章链接，获取网页核对公众号、标题和发布时间。符合范围与时间窗的文章，会去重加入文章库。

这一步是发现并登记文章，不代表正文和图片已经全部下载。到文章库选中需要的内容，再执行文章下载；下载完成后，使用阅读和导出入口，同时得到 Markdown、HTML 与已保存的图片。

要找更早的文章：先做主页识别

推送监测不能代替历史翻页。要整理某个公众号更早的旧文，可以走另一条路径：

1. 在「公众号」页开启「主页识别」，再到微信手动打开目标公众号主页，登记公众号和采集会话。这个动作本身不会采集文章。
2. 需要近期列表时点「同步最新文章」获取首页；需要旧文时点「采集历史文章」，按追加篇数或截止日期创建任务。
3. 列表拿到后，在文章库下载需要的正文和图片。按需单篇、勾选多篇，或整号加入下载队列，已有正文会跳过。
4. 目标正文下载完成，再批量导出 Markdown 和 HTML。导出不会替你补采缺失正文。

主页识别和推送监测是独立开关，可以同时开启。前者为指定公众号准备列表采集会话，后者发现本机微信中可观察到的文章链接。

“发现了链接”，不等于“收全了推送”

监测只能发现进入可扫描内存、并且保留足够久的链接；你手动打开的旧文章也可能被发现。“发现时间”是软件看到链接的时间，不是微信推送送达时间。

微信退出、链接释放或网页不可访问，都可能影响结果。它不能保证补齐离线期间的所有推送，也不承诺固定送达延迟。v2.0.0 重启应用后，推送监测需要手动重新开启；按公众号定时同步、增量采集与正文下载仍是后续计划。

环境和风险，先看清楚

当前 Windows 客户端需要 Windows 10/11 x64、WebView2 和已登录的微信；已验证微信版本为 4.1.15.56 x64，升级后需要重新适配。macOS、Linux 暂不支持这套原生采集。

所有使用个人微信号的客户端都可能存在账号限制或封禁风险，MPider 也不例外。开源、本地运行和低频请求都不是防封保证。请避免使用承载重要联系人、工作或支付用途的账号，只保存自己有权处理的内容。暂不采集视频、音频、评论、阅读量和互动数据。
