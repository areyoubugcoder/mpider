账号是自己的，风险自己承担，导出文章却还要额外付费。这种体验，我不认同。

MPider 选择免费开源，让核心采集逻辑、凭证如何获取和使用都可供核查，把知情权和选择权交还给用户。你可以先看代码和说明，再决定要不要使用。

它的核心功能很直接：公众号监测，以及下载公众号文章。把需要的正文和图片保存到自己的 Windows 电脑后，可以离线阅读，同时导出 Markdown 和 HTML，不为本工具里的文章导出另设收费门槛。

文章列表有了，为什么还要下载正文？

假设你周末想离线看几篇行业长文：文章库里已经出现了标题，但准备批量导出时，发现目标正文还没全部下载。

原因在于，获取文章列表、下载正文、导出文件，是三个分别发起的步骤。列表帮你找到文章；下载才把正文和图片留到本机；导出则把已经下载的内容写成可以带走的文件。

这样做，你可以先挑选需要的几篇，再下载正文，不必把看到的每篇文章都存下来。

按这个顺序，保存一批离线阅读材料

1. 先登记公众号。在 MPider「公众号」页开启「公众号监测」，再到已登录的 Windows 微信里，手动打开目标公众号主页，等待名称与会话登记。
2. 获取文章列表。点击「同步最新文章」获取首页；需要更早的内容时，点击「采集历史文章」，按追加篇数或截止日期创建任务。
3. 下载需要的正文。在文章库勾选目标文章下载，或按需在公众号行点「下载全部正文」。工具保存正文、封面和正文图片，已有正文会跳过。
4. 等目标正文下载完成，再点「阅读 / 导出」。单篇、批量和整号导出会同时生成 Markdown 与 HTML，并附带已保存的图片。

监测本身负责登记公众号和会话，不会自动把文章入库，也不是全天自动追踪更新。需要保存哪些内容，由你分别发起任务。

下载中断以后，先看任务状态

首页同步、历史采集、正文下载在「任务」的不同标签里管理。历史采集可以暂停并保留检查点；需要新会话时，按提示在微信重新打开目标公众号主页，再沿原任务继续。

批量或整号导出之前，确认目标正文都已下载。导出不会自动补采缺失正文；发现缺图时，也要检查保存结果，不能把出现一个 HTML 文件就当作所有图片都完整了。

导出以后，可以怎么用？

HTML 适合用浏览器打开阅读，Markdown 适合放进自己的笔记目录继续整理。保存导出目录时，把图片文件一起保留；需要完整备份应用数据时，应备份「系统设置」显示的完整数据目录，普通导出不能替代任务和会话备份。

先确认适配范围，再决定使用

当前原生采集支持 Windows 10/11 x64，需要 WebView2，已验证微信 4.1.15.56 x64。微信升级后需要重新适配，macOS、Linux 暂不支持。

所有使用个人微信号的客户端都可能有账号限制或封禁风险，MPider 也不例外。免费、开源、本地运行都不是账号安全保证，请避免使用承载重要联系人、工作或支付用途的账号，只获取和保存自己有权处理的文章。

当前不采集视频、音频、评论、阅读量和互动数据；定时自动增量采集仍是后续计划。
