账号是自己的，风险自己承担，导出文章却还要额外付费。这种体验，我不认同。所以 MPider 选择免费开源：让核心采集逻辑和凭证处理可以被核查，把知情权和选择权交还给用户。

工具能做的事情很具体：公众号监测，以及下载公众号文章。你可以在自己的 Windows 电脑上登记公众号、获取历史文章列表，把正文和图片保存下来，再离线阅读或导出 Markdown、HTML。

今天换一个场景：整理一次活动的公众号资料

![文章库用于查看文章列表、下载正文与导出离线文件（演示数据）](../../assets/blog/workbench-articles.png)

文章库用于查看文章列表、下载正文与导出离线文件。截图为公开版本的演示界面，具体操作以本文注明的版本和最新发行说明为准。

比如，你要回看自己有权保存的一组活动推文：最初怎么预告，报名说明写了什么，活动结束后又发布了哪些回顾。只留几条链接，翻阅时还得逐篇打开；把需要的正文和配图保存到本地，后续整理资料会更直接。

MPider 负责把文章保存好。活动时间线、对比笔记和复盘结论，可以在导出后由你自己整理。

第一步：开启公众号监测，先登记目标公众号

打开 MPider，在「公众号」页开启「公众号监测」，然后到已经登录的 Windows 微信中，手动打开目标公众号主页。等待名称和会话登记完成，再发起后续任务。

这里的“监测”是登记公众号及其会话，不是全天自动盯更新。只打开监测，不会自动把文章列表或正文下载到电脑。

第二步：按需要获取新文或旧文

只想看近期内容，就在该公众号行点击「同步最新文章」，获取首页。

需要往前找活动推文，就点击「采集历史文章」，按追加篇数或截止日期创建任务。列表采集和正文下载分开控制，不需要看到一条就立刻下载一条。

历史采集支持暂停并保留检查点。任务提示需要新会话时，按说明在微信重新打开目标公众号主页，完整会话到齐后再沿原任务继续。

第三步：下载需要的文章，再导出

在文章库勾选需要的文章下载正文；如果确实需要整号保存，也可以在对应公众号行点击「下载全部正文」。工具会保存正文、封面和正文图片，已有正文会跳过。

正文下载完成后，再使用「阅读 / 导出」。单篇、批量和整号导出会同时生成 Markdown 与 HTML，并附带已保存的图片。批量或整号导出前，先确认目标正文已下载；导出不会替你补采缺失正文。

HTML 可以直接用浏览器打开，Markdown 可以放进自己的笔记目录。你可以另建一份活动清单，记录预告、报名和回顾分别对应哪些文章，保留来源，再写自己的复盘笔记。

使用前，确认环境和风险

当前这套原生采集面向 Windows 10/11 x64，需要 WebView2，已验证的微信版本为 4.1.15.56 x64。微信升级后需要重新适配，macOS、Linux 暂不支持。

MPider 使用本机已登录的微信会话，不将个人微信凭证上传到云端账号池；但开源和本地运行都不能保证账号安全，仍有账号受限或封禁风险。请避免使用承载重要联系人、工作或支付用途的账号，只获取和保存自己有权处理的内容。

当前不采集视频、音频、评论、阅读量和互动数据；定时自动增量采集仍是计划方向，不能用它承诺无人值守地追踪所有更新。
