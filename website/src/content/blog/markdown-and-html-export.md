文章保存到本地后，常见需求有两种：继续做笔记、整理文字，或者用浏览器直接阅读。MPider 同时导出 Markdown 与 HTML，不需要为了得到另一种格式重新采集一遍。

## Markdown 适合后续文字整理

Markdown 用纯文本表达标题、段落、列表和链接，适合放进支持该格式的笔记工具，也便于全文检索、版本管理与二次整理。

导入具体笔记软件后，图片路径、特殊排版和扩展语法的显示效果取决于该软件。支持导出 Markdown，不等于承诺与所有笔记产品都有原生集成，也不保证完整复刻公众号原页面。

## HTML 适合在浏览器直接阅读

HTML 文件可以由浏览器打开，适合把已归档的文章连同本地图片一起回看，也方便在同一文件夹中保留可阅读的文章副本。

离线阅读依赖正文与相关图片已经保存。只复制一份 HTML、遗漏旁边的资源目录，可能导致图片无法显示。

## 批量导出前，先把正文下载完整

文章列表、正文保存与导出是不同步骤。进行批量或整号导出之前，先确认目标文章的正文已经下载完成，再检查导出结果中的文件、索引与图片。

MPider 的导出结果会同时包含两种格式，以及已保存图片和相关清单。具体输出内容与操作说明见[文章导出文档](https://github.com/areyoubugcoder/mpider/blob/main/docs/article-export.md)。

## 保留来源，避免把归档变成失去上下文的素材

建议在整理时保留原作者、公众号名称、文章标题、原文链接和自己的阅读备注。个人保存、摘录和再次发布是不同用途；文章权利仍属于原作者及权利人，只处理你有权获取和使用的内容。

如果还没有开始保存文章，可以先阅读[公众号文章本地留存步骤](../local-article-archive/)，并确认自己理解使用个人微信会话的风险。
