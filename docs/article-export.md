# 文章导出

公众号整号、单篇及勾选文章使用同一条导出流程：一次导出同时生成 Markdown 和 HTML，不需要分别选择格式，也不会重新请求微信或下载图片。开始前必须已经下载全部所选正文；取消文件夹选择时不写文件。

在「公众号 → 公众号列表」中，点击该号操作列的「导出所有文章」，再点击「选择导出路径」。范围为该公众号本地已入库的全部文章，包含所有分页，不会自动采集尚未入库的历史文章。有缺失正文时先完成下载，再导出。

选定目录开始写出后，窗口底部显示「文章导出」进度。切换页面后仍可查看；整号、单篇和勾选导出共用该进度。完成或失败后自动隐藏，无导出任务或取消目录选择时不显示。

导出为文件夹，不生成 ZIP。目录结构与 mphistory 的文章归档一致：

```text
公众号名_年份或年份范围/
├── index.html
├── articles/
│   ├── 0001_文章标题.html
│   ├── 0001_文章标题.md
│   └── …
├── images/
│   └── 图片内容哈希.png
├── manifest.csv
└── README.txt
```

双击 `index.html` 即可离线浏览，支持搜索标题。文章按发布时间倒序排列，序号至少四位；标题会替换 Windows 非法文件名字符、限制长度，序号避免同名覆盖。文章有返回目录与原文链接，底部附有 Mp2RSS 与 MPHistory 的产品介绍和官网链接；HTML 与 Markdown 均保留该介绍。HTML 和 Markdown 共用根目录 `images/`，相同图片内容只保存一次。发布时间按北京时间显示。`manifest.csv` 使用 UTF-8 BOM，列为 sn、标题、发布时间、原文链接、类型和正文状态，可用 Excel / WPS / Numbers 打开。

优先从数据库保存的原始 HTML 提取正文，保留段落、字号、颜色、居中、间距、图片宽度与已有本地背景图等内联排版，再从同一正文生成 Markdown。没有缓存 HTML 的旧库回退到已有 Markdown；此时无法恢复原始排版。正文解析仍使用 `article-md`，第三方 MIT 声明保留于 [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md)。

导出只使用已有本地图片。脚本、事件属性、表单、内嵌页面与远程 CSS 资源会被移除，未保存的图片显示提示，不会在打开 HTML 时自动联网取图。视频、音频保留原文观看或收听说明；复杂交互、微信专用组件和付费全文不在导出范围内。缺图提示保留于文章和 `README.txt`，清单中的「成功」表示正文成功导出。

读取本地归档时校验目录和文件类型；跨电脑复制的数据库若没有对应归档目录，使用数据库已有正文。不会附带 `original.html`、凭据文件、原始协议响应及协议证据；归档中的 `original.html` 仅在数据库没有 HTML 时用于提取和清洗正文。原文 URL 与 HTML 超链接移除已知会话参数（`key`、`pass_ticket`、`uin`、`wxtoken`）及 URL 用户信息。正文文字本身不会自动脱敏，分享前应自行检查。只有 Markdown 的旧库仍可能含远程图片链接，第三方 Markdown 阅读器可能自行加载。

写入失败只清理本次暂存目录，全部成功后整体发布。目标目录同名时增加后缀，不覆盖已有导出或用户文件。
