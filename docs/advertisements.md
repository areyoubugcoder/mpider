# 底部广告位

广告内容维护在 [`config/advertisements.json`](../config/advertisements.json)。发布到 GitHub 的 `main` 后，已安装应用会在启动时及每 30 分钟读取该文件的公开 Raw 地址，无需重新打包。

当前固定地址：`https://raw.githubusercontent.com/areyoubugcoder/mpider/main/config/advertisements.json`。仅在本地分支修改不会影响已安装应用；文件尚未发布、断网或加载失败时会使用最近有效缓存，缓存不可用则显示随应用打包的默认配置。

## 配置契约

```json
{
  "version": 1,
  "enabled": true,
  "interval_seconds": 6,
  "items": [
    {
      "id": "mp2rss",
      "enabled": true,
      "title": "持续订阅公众号更新 · MP2Rss",
      "compact_title": "公众号持续订阅 · MP2Rss",
      "url": "https://mp2rss.bugcode.dev/?from=mpider"
    }
  ]
}
```

所有字段必填。配置总大小最多 32 KiB，`version` 固定为 `1`，轮播间隔为 5～60 秒的整数。最多 12 条广告，按文件顺序播放；`id` 唯一、最多 64 字符，完整文案最多 160 字符，`compact_title` 为旧版窄窗口保留兼容、最多 80 字符，链接最多 2048 字符且必须为不带用户名和密码的 HTTPS 链接。

修改 `title`、`url` 即可更换文案和目标地址；增加或移除 `items` 条目即可调整广告数量。单条 `enabled: false` 暂停该条广告；顶层 `enabled: false`、空列表或所有条目停投时隐藏广告位，其余状态栏保留。反馈入口独立放在左侧菜单。

配置只支持纯文字和链接，不支持 HTML、脚本或远程图片。任意条目不合规时整份远程配置不予采用，保留之前有效内容。

## 播放与回退

- 广告与任务进度、监测状态共用一行底栏。广告在最左侧，宽度在 11～23 rem 之间随窗口调整，不被右侧内容挤占；监测状态位于最右侧，底部只读，操作仍在公众号页首卡片。
- 多条广告按配置间隔向上循环，过渡为 650 毫秒；单条静态显示。广告动画独立于 Windows/RDP 的减少动态效果设置，不修改系统动画偏好。配置更新后从第一条开始。
- 长广告在固定宽度内以省略号展示，不做横向滚动。悬停或键盘聚焦时暂停轮播，通过浮层显示当前完整文案和目标地址，浮层本身不新增网络请求。
- 不显示“推荐”标签、图标、暂停或上一条/下一条按钮。没有有效广告时隐藏整个广告位，不增加空白广告行。
- 读取超时为 5 秒。HTTP 错误、JSON 损坏、格式不合规或网络不可达均回退，不弹错误、不阻塞工作台。
- 最近有效配置在本机缓存 7 天；缓存损坏、过期、来自未来或存储不可用时使用内置内容。缓存仅包含广告配置及保存时间。
- 应用启动及每 30 分钟会向 GitHub 发送公开配置请求，不携带 Cookie、页面来源、账号、日志或会话材料。GitHub 仍会收到访问 IP 等常规网络信息；没有广告曝光统计或点击上报。只有点击广告才打开目标网站。

## 本地验证

`pnpm test` 包含广告契约及真实本地 HTTP 读取测试，覆盖成功更新、缓存不可写、404、500/HTML、损坏 JSON、无效配置、超限配置、超时和服务不可达。测试不连接 GitHub，也不启动微信监测。

前端开发时可以设置 `VITE_ADVERTISEMENTS_URL` 指向本地 HTTP 服务提供的 JSON 地址；浏览器访问不同端口时，该服务需要允许跨域读取。该覆盖只在 Vite 开发模式生效，发行包始终使用上述 GitHub Raw 地址。
