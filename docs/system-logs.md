# 系统日志

从左侧“系统日志”查看应用启动、公众号监测、列表采集、正文和图片下载、导出、存储及请求策略的运行记录。日志保留近 3 天，最多 50,000 条，较旧记录会自动清理。

## 查看与筛选

可组合业务模块、日志级别、起止时间、关键字和任务 ID。筛选针对全部匹配记录，随后分页；默认每页 10 条，可选 20 / 50 / 100 条。列表按新到旧排列，首页可以自动刷新，翻到旧页后暂停刷新。

列表请求中的“返回篇数”“新入库篇数”和“已完成篇数”含义不同：重复文章仍属于有效响应，但不会重复入库。HTTP 成功也不代表正文或文章列表已保存，请结合后续处理结果查看。排查异常时可先暂停任务，再按任务 ID、模块和时间范围缩小记录。

## 导出与反馈

“导出系统日志”支持 JSON 和文本，包含全部符合当前筛选的记录、筛选条件及保留策略，不受当前页限制。选择保存位置后写入，取消不生成文件。导出动作本身在保存成功后才记录，因此不在本次文件中。

程序会过滤密钥、原始游标、会话文件和完整协议报文，并对已知敏感字段与链接脱敏。日志仍可能带有公众号名称、任务信息或用户输入；公开反馈前应自行检查，只提供问题所需的最小片段。不要附带数据库、受保护会话或原始协议材料，参见[安全政策](../SECURITY.md)。
