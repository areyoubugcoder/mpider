# 底部任务进度、实验室开关与文章操作

底部只在对应队列存在未结束任务（queued/running/paused/needs_action）时显示进度。正文下载与历史采集整块区域可点击，悬停/聚焦提示对应任务入口，分别直接进入任务页的正文下载/历史采集标签；不再弹出下载队列。统计只包含当前未结束任务，来自全库聚合，不依赖1000条快照；篇数目标显示已完成/目标总数，含日期或单页任务时总数未知，显示已采集篇数和任务数，不声称百分比。所有任务完成、失败或取消后隐藏对应进度；暂停/等待主页的任务保留入口。

快照新增 active_queues: { download, history }，每项为 {task_count,completed,total:number|null}。原 download_queue 保留全量历史汇总以兼容现有快照，底栏不再读取它或另行加载队列弹窗。

实验室入口由系统配置中的“显示实验室”控制，默认false，本机持久化；关闭时离开实验室页面，保留实验数据和后台已启动实验。移除侧栏脚注文案和底部近24小时列表请求统计。限流分析移除请求间隔折线图，保留统计、策略及明细。

文章列表增加 has_body，按本地非空Markdown正文判断，不用detail_done或旧任务完成状态代替。未下载只显示下载；已下载只显示阅读和导出，原文入口保留。勾选后下载仅处理未下载项，导出需全部已下载；选中项跨页通过批量状态查询更新。导出在打开目录选择前及实际写入前校验正文，未下载时不产生导出文件。

验证：核心库全量285项及新增全库队列/正文状态回归通过（另3项忽略）；20项Node测试、TypeScript、前端构建、Rust格式与全目标Clippy通过。Headless浏览器验证空/活动/结束队列、整块悬停点击、历史标签跳转、未知总数、实验室默认隐藏及重载持久化、无折线图、文章下载/阅读/导出互斥、混合及跨页选择仅下载缺失正文、深色窄屏。数据均为虚构夹具，未进行真实采集。
