# 任务标签页、统一分页与 ZIP 归档移除

任务页分为首页同步、历史采集和正文下载三个标签页，切换标签回到第一页；底栏正文下载/历史采集进度直接进入对应标签，不再经过队列弹窗。所有结果列表使用总条数、每页条数、上一页/下一页和数字页码，默认每页10条，可选20/50/100；空列表和单页也保留分页栏。过滤或切换每页条数回到第一页，删除导致页码越界时回到最后有效页，后台新增数据不会强制跳回第一页。

公众号、任务、请求明细和系统日志按数据库完整匹配范围计算总数并分页，不能将工作台快照的1000/2000条截断当作完整数据。文章库复用已有后端分页。下载队列、实验游标列表、验证时间线与对照记录使用同一分页展示规范。

新增 IPC：`workbench_source_page(search,limit,offset)`、`workbench_task_page(kind,limit,offset)`、`workbench_request_page(category,since,limit,offset)`，返回 `{items,total}`。公众号项附带当前首页/历史任务，避免快照截断遗漏旧任务；任务类型 archive 只接受正文下载。系统日志 `workbench_logs` 增加可选 offset；旧 beforeId 游标调用继续兼容，导出仍包含全部匹配记录。

移除文章 ZIP 归档的创建、恢复、调度和打包路径，以及“打开归档包”入口。原归档任务在重启时取消，不删除已有数据库记录或磁盘文件。内部 archive 类型和缓存目录保留用于正文、图片下载及本地阅读；Markdown和实验数据导出保留。

验证：核心库285项通过、3项忽略；Markdown解析14项通过；前端类型检查、构建和20项Node测试通过；headless浏览器覆盖全部当前列表的默认10条、数字跳页、空/单页、每页条数、筛选、标签键盘、轮询保页、删除越界、下载/阅读/导出及深色窄屏。回归包含1005条任务、2106条请求的真实数据库分页及旧ZIP取消流程，使用虚构内存数据。
