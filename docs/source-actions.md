# 按公众号操作与独立监测

公众号监测独立开启，负责发现公众号、登记首页会话与游标；监测结果全部进入公众号列表。监测不自动入库文章、不自动创建采集任务，也不操作微信 GUI 或改变窗口状态。旧的全局采集范围不再生效。

每行按状态提供“同步最新文章”“采集历史文章”，正文尚未齐备时显示“下载全部正文”，全部正文已下载后改为“导出全部文章”；无文章时不显示整号下载/导出。首页同步创建 `home` 单页任务，使用该公众号最新已保存会话和无游标首页请求，遵守共享列表锁、间隔、预算及冷却。成功才入库首页文章并更新当前游标；历史检查点、缓冲、已有历史任务与固定实验保持原状。重复点击复用未结束的首页任务。

历史采集在该公众号的弹窗选择篇数或截止日期，只为该行创建任务。没有可用会话时，任务启动监测并提示用户打开该公众号主页；收到目标新会话后自动继续。首页同步与历史任务均可暂停、取消和恢复；新响应不得复活已取消任务。旧公众号没有现代会话时，先登记待监测状态，首次捕获新首页后准备请求。

IPC：`workbench_sync_home(biz)` 返回首页任务 ID；复用 `workbench_history(bizzes,target)` 时前端传入单个公众号。`workbench_home_sync_start(pythonPath)` 仅开启监测；旧 `workbench_discovery_start` 不接受全局采集目标。普通响应不包含原始游标、会话密钥或保护文件路径。

公众号、任务、文章库及实验室的所有操作列使用可键盘操作、支持禁用与焦点状态的文字操作，取消按钮边框、底色、图标和固定按钮高度。弹窗内的提交/取消保留标准控件。

## 验证范围

离线测试使用虚构 IPC 与子进程响应，覆盖按公众号隔离、任务状态、会话等待、原游标恢复及显示契约。它们不替代真实 Tauri、握手认证和微信采集验收。公开截图使用演示数据，详见 [验证范围](windows-workbench-validation.md)。

## 列表展示细化

“最近监测 / 采集”以“刚刚、N分钟前、N小时前、N天前”等相对时间显示，每30秒更新本地时钟；悬停保留完整时间，未知时间显示“—”。已有首页/历史任务时，每类只显示一个主操作：运行或排队时暂停，暂停或失败时继续/重试，会话失效时更新会话，等待新会话时撤销自动继续。取消任务收纳至“更多”；任务结束或取消后重新显示创建入口。任务页与实验室的单页采集操作遵守相同状态规则。

`workbench_source_page` 的每行增加 `body_count`，与 `article_count` 在同一读事务中统计全部未删除文章，以非空 Markdown 正文为准，不依赖 `detail_done`、分页展示或快照上限。前端据此选择整号下载/导出，真正导出时后端仍重新校验正文。

文章行未下载时只显示下载，下载后显示阅读和导出；阅读与导出用途独立。批量选择正文未齐时只显示下载缺失项，全部正文齐备后才显示导出。实验室存在未结束历史任务时不显示“获取下一页”，改为该任务当前可执行的主操作；已有同游标实验运行时不显示重复复测入口。

本次展示调整通过 TypeScript、Vite 构建及17项 Node 展示契约检查；无界面浏览器验证了本地时钟推进、首页/历史六种任务状态的互斥入口、日志标签位置、当前模块筛选与旧日志读取、导出参数及深浅主题/窄视口布局。验证使用虚构数据，没有操作专机窗口或发送真实采集请求。

## 文章定位与公众号删除

公众号操作列的“查看文章”进入文章库并按该公众号筛选，切换筛选时回到第一页并清空勾选。从侧栏“文章库”进入时显示全部公众号。“更多”保留取消任务，并提供“删除公众号”；需在弹窗中再次确认，执行范围以确认时该公众号的全部文章为准。后台删除与在途响应保护见[公众号删除](source-deletion.md)。

导出同时生成 Markdown 和 HTML；单篇、勾选与整号流程一致，见[文章导出](article-export.md)。
