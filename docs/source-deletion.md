# 删除公众号与关联数据

在公众号列表选择“删除公众号”，核对名称和提示后确认。此操作会删除该公众号的文章、正文、阅读缓存与本地图片，并从公众号列表和文章筛选中移除。删除不可撤销，操作前按需要备份完整数据目录或导出文章。

该号尚未结束的首页、历史、单号下载任务和实验会取消。跨公众号下载任务仅移除该号文章，其他公众号继续处理。已结束任务、请求账本、实验记录、受保护会话及游标证据保留用于本机审计；用户此前导出到其他位置的文件不由此操作清理。

文件被占用或权限不足时，已提交的数据删除不会撤销。界面会提示缓存仍待清理，后台会重试，重启后继续。此操作不承诺擦除 SQLite 空闲页、系统备份或外部副本，也不会发送微信请求。

需要重新添加时，开启监测并重新打开目标公众号主页。删除前已发出的迟到响应不会重新登记该号；应等待新的主页请求。重新添加后，旧任务和旧下载结果不会重新写回已删除的文章。
