# 会话采集与恢复

当前工作台使用 Windows 原生观察器登记公众号和会话，之后由独立协议工作进程请求列表。监测与采集意图分开管理，操作步骤见 [原生采集](native-collector.md)。

## 会话登记

监测开启后，用户手动打开目标公众号主页。观察器核对模块摘要、函数指纹、桥请求与唯一匹配的响应，并认证密钥与业务模板。只识别到公众号或首页响应不代表完整会话已交付。监测只登记公众号、会话和首页游标，不自动采集文章。

公众号名称来自匹配响应，身份还需核对客户端账号和文章链接的 `__biz`。前端不接收密钥、原始游标或完整协议载荷。

## 列表任务

首页同步与历史采集由用户按公众号单独发起，首页同步不覆盖历史检查点。历史任务使用服务端返回的不透明游标，按追加篇数或截止日期停止。发送独立请求前先持久化计账，响应通过认证、业务结果和身份校验后，文章与新检查点在同一事务提交。

会话失效会暂停。程序记录失效会话版本；只收到首页响应、尚未收到完整新会话时不会恢复。更新同一公众号的完整会话后，原任务保留原游标、累计进度及历史检查点继续。暂停、取消或关闭监测会撤销自动继续意图。

## 数据保护与环境

发行包携带固定 Python、Frida、cryptography 依赖，程序优先发现旁边的 `runtime/python.exe`。开发环境可按 [Windows 运行说明](windows-standalone.md) 单独准备依赖。

会话材料保存于应用数据目录的受保护存储。DPAPI 文件仅供同一 Windows 用户使用；显式会话导出属于敏感诊断操作，不能将导出内容加入反馈、公开日志或测试夹具。

当前采集只适配微信 4.1.15.56 x64。会话与游标没有统一寿命保证，长期无人值守和不同微信版本的兼容性未获保证。加密与字段说明见 [协议设计](wechat-session-protocol.md)。
