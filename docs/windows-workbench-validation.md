## 采集验证边界

当前适配 Windows x64 微信 4.1.15.56 的精确模块与函数指纹。早期验证观察到公众号识别、独立列表请求、游标推进与去重，这些观察仅说明对应样本；不代表本次发行的每个 GUI 流程均完成真实采集验收。

Frida 附加曾导致微信异常退出，长期稳定性仍需验证。会话有效期与游标有效期分别判断，不提供统一 TTL、平台配额或免限制保证。未知微信指纹拒绝运行。

普通 CI 使用虚构夹具，不附加微信或发送真实采集请求。发行安装验收使用独立演示数据，不读取或操作现有微信会话。

## 公开证据要求

记录版本、产物摘要、操作与结果即可。公开资料不包含真实账号、专机地址、用户名、绝对路径、会话材料、原始游标、私有日志链接或逐次操作时间线。README 截图使用明确标注的虚构演示数据。

## 已完成的真实安装与升级验收

正式发行准备阶段使用真实签名构建与 GitHub 稳定更新地址，完成以下验证：

- Windows MSI 安装、桌面启动及卸载，独立演示库中的正文可离线阅读。
- 清理后初始源码构建的 NSIS 0.2.0 安装与启动。
- 0.2.0 客户端检查公开 0.2.1，完整下载真实安装包；缓存 SHA-256 与 Release 一致，版本绑定签名有效。
- 通过客户端确认安装并自动重启，新进程及界面均为 0.2.1，随后检查显示已是最新正式版本。
- 更新前后核对原有文章正文、配置及归档文件摘要，结果一致；SQLite 完整性检查正常。

原始核对材料与完整备份仅留在验证环境，不作为公开附件。此流程没有开启微信监测或新增真实采集请求。1.0.0 最终产物的构建及安装结果以对应 Release 验收说明为准。
