# Windows 原生采集

当前工作台按公众号分别管理监测、首页同步、历史采集和正文下载。完整使用步骤见 [README](../README.md) 和 [Windows 运行说明](windows-standalone.md)。

1. 开启公众号监测，在微信中手动打开目标公众号主页。
2. 等待公众号与完整会话登记；监测本身不会入库文章。
3. 在对应公众号行发起首页同步或历史采集。历史进度按检查点保存。
4. 需要新会话时，在监测开启期间重新打开或刷新目标主页，等待完整会话交付。
5. 单独下载正文和图片，再进行离线阅读及 Markdown / HTML 导出。

程序不自动点击、刷新或滚动微信窗口。当前原生采集仅适配 Windows x64 微信 4.1.15.56 的精确模块与函数指纹，未知指纹拒绝运行。

默认频率不是平台安全配额。异常会暂停任务；会话与游标的有效期分别判断。参见 [请求策略](request-policy.md)、[会话恢复](home-sync-recovery.md) 和 [协议设计](wechat-session-protocol.md)。

会话与原始协议材料由当前 Windows 用户 DPAPI 保护，不属于普通导出内容。不要提交数据库、原始会话、抓包或本机诊断材料。
