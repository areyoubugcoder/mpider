# 游标有效期与会话过期

游标是服务端返回的不透明分页状态，会话是独立请求所需的认证材料。二者必须分别判断。会话失效不能直接证明游标过期。

## 已有观察的边界

早期单公众号观察中，旧游标曾在取得约 33 小时后配合新会话成功复用。该结果只说明一个成功样本，不是所有公众号的最低有效期、闲置寿命或精确 TTL。没有经过失败对照确认的游标到期上限，不能用固定小时数淘汰所有检查点。

同一旧游标在失效会话下失败、更新会话后成功，支持将会话失败与游标失败分开分类。该历史观察不能作为本次发行完整 GUI 恢复流程或长期稳定性的验收证据。公开资料不包含原始游标、账号、请求时间线或私有材料链接。

## 复测方法

- 取得使用授权，使用独立数据目录，记录游标首次取得时间与会话版本。
- 先做即时成功基线，再固定同一游标及会话进行有预算的延时观察。
- 会话失败时停止原实验；更新会话后另建复测，保留旧实验及其固定输入。
- 核对双层认证、公众号身份和业务结果，不把网络错误或会话超时归类为游标到期。
- 实验只写独立记录，不推进正式任务游标、文章库或历史检查点。

离线回归可验证恢复契约与状态隔离，无法测量服务端 TTL。当前实验入口默认隐藏，使用方式见 [游标实验室](laboratory.md)。
