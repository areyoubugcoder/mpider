# 原生观察器稳定性边界

历史验证曾记录微信异常退出，故障模块指向 Frida 探针运行环境。该现象说明附加和生命周期操作存在稳定性风险；仅凭故障模块与异常码，无法确定具体触发动作，也不能推断为会话、游标或频率限制问题。

短时采集成功不代表长期附加稳定，当前版本不宣称已修复全部 Frida 稳定性问题。出现异常应停止监测和任务，保护已保存进度，再按 [安全政策](../SECURITY.md) 检查脱敏后的诊断范围。

排查时分别核对模块及函数指纹、单观察器生命周期、停止与回收、Windows 事件和必要的受控转储。原始报告可能包含用户名、路径、账号或进程材料，应保留在本地，不自动附加到公开 Issue。
