# 开发与开源发布基线

公开项目为 `areyoubugcoder/mpider`，主分支为 `main`。开发、验证与发行应以当前主线和对应标签为依据，记录实际源码提交和附件摘要。

## 当前功能

- 公众号监测登记公众号、会话与游标，首页同步和历史采集由用户按公众号单独发起。
- 首页、历史与正文任务分别管理，按检查点保存进度，支持暂停和会话更新后续采。
- 文章库支持公众号筛选、正文下载、离线阅读和确认删除，同时导出 Markdown、HTML、索引与已保存图片。
- 列表、正文与图片按独立配置执行间隔、并发和预算，共享异常冷却并保存请求账本。
- 系统日志支持筛选与导出；游标实验室默认隐藏，按设置显式开启。
- Windows 安装版支持 GitHub 版本检查、签名预下载、缓存恢复和确认安装。

当前原生采集支持 Windows x64，适配版本、精确指纹与实际验证范围见 README 和工作台验证记录。构建、离线回归、桌面启动和真实采集的结果分别说明。

## 协作流程

1. 从 `main` 创建独立 worktree，使用 pnpm 安装依赖与执行前端命令。
2. 完成功能、文档与相应验证，保护已有数据；普通开发和 CI 使用虚构测试材料。
3. 按已有授权与分支规则提交和合并 PR。合并成功后按协作约定清理本次 worktree 和工作分支。
4. 发行标签与三处项目版本一致，核对源码 revision、文件 SHA-256、签名与完整运行环境。

## CI 与发行

CI 运行前端类型、构建、Node/Python 离线回归，以及 Windows Rust 格式、Clippy 和测试。客户端发行提供 Windows x64 便携 ZIP、NSIS 和中文 MSI，包含固定 Python/Frida 环境、许可、自检记录及更新清单。

离线检查不代表真实微信采集、长期稳定性或两个正式版本间升级已经通过。正式发布前按对应 Release 说明核对附件、签名、更新地址与验证范围。
